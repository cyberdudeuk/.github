# Contributing

Thank you for helping. Every project here is built in the open and checked automatically before anything is published.

## Ways to help

- **Report a problem or suggest an idea:** open an issue in the project's repository. Issues labelled
  [good first issue](https://github.com/search?q=user%3Acyberdudeuk+is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22&type=issues)
  are a good place to start; [help wanted](https://github.com/search?q=user%3Acyberdudeuk+is%3Aissue+is%3Aopen+label%3A%22help+wanted%22&type=issues)
  marks bigger pieces where help is especially welcome.
- **Change something:** fork the repository, make the change on a branch, run the project's checks, and open a pull
  request. Each project's README says how to run its checks.
- **Ask a question:** use the project's Discussions tab where it has one, or the
  [contact form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=contact.yml).

## What to expect

- A pull request is merged once its checks pass and it has been reviewed. If a check fails, the message says why.
- If you fix a defect, add a check that would have caught it, in the same pull request.

## Ground rules

- Plain English, sentence case, and no email addresses or personal data in issues, code or content.
- Every figure or claim links to its source.
- By contributing you agree your contribution is published under the project's own licence.
- Follow the [code of conduct](CODE_OF_CONDUCT.md).
