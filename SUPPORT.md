# Getting help

| You want to… | Do this |
|---|---|
| Learn how to use a project | Read its README, then its live site, listed on [Public Good Works](https://cyberdudeuk.github.io/). |
| Ask a question | Use the project's Discussions tab, or the [contact form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=contact.yml). |
| Report something that does not work | Open an issue in the project's repository. |
| Report a security problem | Follow [SECURITY.md](SECURITY.md); do not open a public issue. |
| See what is being worked on | The [Public Good Works board](https://github.com/users/cyberdudeuk/projects/4). |

Issues are public: don't include personal data or anything sensitive. Projects are maintained by one person, so
replies are best effort. There is no telephone or email support.
