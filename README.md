# Default community files for cyberdudeuk

This repository holds the community files every public repository on the
[cyberdudeuk](https://github.com/cyberdudeuk) account falls back on. GitHub uses a file here only when a repository has
no file of its own of that kind ([how defaults work](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).

| File | What it is for |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | How we treat each other, and how to report a problem |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to suggest a change, and how quickly to expect a reply |
| [SECURITY.md](SECURITY.md) | How to report a security problem privately |
| [SUPPORT.md](SUPPORT.md) | Where to get help |
| [.github/ISSUE_TEMPLATE/config.yml](.github/ISSUE_TEMPLATE/config.yml) | Links shown when someone opens an issue |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | The checklist on every pull request |

Most projects carry their own, more specific versions of these files; those always win. Licences are never inherited:
each repository states its own.

All the projects are listed on the launchpad, [Public Good Works](https://cyberdudeuk.github.io/). Contact is by the
[contact form](https://github.com/cyberdudeuk/cyberdudeuk.github.io/issues/new?template=contact.yml) only.
